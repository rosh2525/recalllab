# Contributing

Run scripts/verify_release.py before proposing a change. Keep math grading deterministic and learner input bounded. Do not expose unfinished check assessments, answers or rubrics through public catalog responses. New questions need original or openly licensed source notes, graduated hints, an explicit expected result or reviewed rubric, and at least one wrong-answer fixture.

Keep model feedback limited to reviewed templates and allowlisted diagnostic IDs. Model errors must abstain and keep learner work. Never commit data/, .env, credentials, private course files or student responses. The local prototype has no multi-user authentication; public hosting needs a separate design and review.
