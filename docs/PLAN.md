Accepted scope: one local learner, mathematics for economics, React/Vite/TypeScript, FastAPI/SQLite, official Streamable HTTP MCP, optional Bedrock Nova Lite. Public hosting and native Alexa+ belong after v1.

| Deliverable | Status | Evidence |
| --- | --- | --- |

| Attempt → hint → retry → independent check | Complete locally | Server-enforced workflow and browser QA |
| Reliable numeric/polynomial grading | Complete | Bounded parser and mathematics fixtures |
| Saved attempts, assistance, content version, review dates | Complete | Transactional SQLite; restart/concurrency tests |
| MCP discovery and tool calls | Complete | Four tools; official Python and browser clients |
| Reviewed misconception feedback | Implemented, live validation pending | Allowlisted diagnostic IDs, fixed feedback, contradiction rejection |
| Editable speech and read-aloud | Implemented | Unsupported recognition preserves typed answers; live microphone trial pending |
| Keyboard, responsive UI, source dialog | Checked on representative flows | Validation record; full assistive-technology audit pending |
| Bedrock connection and real assessment | Blocked externally | Authentication works; AWS account restriction; AWS Support declined access; latest retry remains blocked |
| ≥90% agreement on 60 held-out reviewed responses | Pending | Candidate cases and independent-review sheet ready; no live accuracy claim |
| Five student interviews and pilot | Needs consenting participants | PILOT.md, interview guide, observation sheet and parallel follow-up forms |
| Measured cloud cost | Pending successful inference | Token accounting and benchmark report; no invented cost |
| Reproducible package, product feedback, friction log | Complete | README, release verifier, CI, SUBMISSION.md, PRODUCT_FEEDBACK.md |
| English demo under three minutes | Script ready; recording/upload pending | DEMO.md and DEMO_NARRATION.md |

Implementation tests and scripted QA are not student research. Developer-authored benchmark labels are not independent educator review. The remaining human and AWS-dependent evidence must be collected before claiming those milestones.
